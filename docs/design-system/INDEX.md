# Дизайн-система DnDisc — выгрузка для разработки

Копия дизайн-системы DnDisc для работы над UI в этом репозитории. Источник правды — артефакт дизайн-системы; при расхождении эту папку обновляют из него, а не правят вручную.

Читать в таком порядке:

1. `README.md` — принципы, цвет, темы, типографика, отступы, состояния, иконки, формы и слои.
2. `tokens.json` — все токены: цвета по темам (`deep-dark`, `clean-light`), типографика, `spacing`, `radius`, `size`, `shadow`, `duration`, `easing`, `zIndex`.
3. `layout.md` — раскладка экранов и брейкпоинты (≥1000px, 700–999px, <700px).
4. `flutter.md` — как перенести систему во Flutter: поля `CustomThemeModel`, `toThemeData()`, константы, иконки, обложки, диалоги, редактор темы, порядок работ.
5. `components/<Имя>.md` — правила каждого компонента: что передаётся, размеры, состояния, что запрещено.
6. `audit.md` — что было не так в старом интерфейсе и какое решение принято.

Остальное:

- `screens/*.png` — эталонные экраны: `main.png` (GM Dashboard, Deep Dark), `main-clean-light.png`, `compact.png` (окно 720px), `library.png`, `catalog.png`, `settings.png`, `dialogs.png` (создание сцены, удаление, меню, подсказка, уведомления), `covers.png`, `icons.png`.
- `reference/bundle.css`, `reference/bundle.js`, `reference/index.d.ts` — веб-реализация компонентов, по которой нарисованы экраны. Использовать как справочник точных размеров, отступов и состояний (классы `dd-*`), а не как код для переноса.
- `assets/Icons/*.svg` — 65 значков (24×24, линия 1.75), имя файла = ключ значка. Чернила `#b8a999` только для просмотра; в приложении цвет задаётся темой.
- `assets/Covers/*.svg` — 7 обложек сцен по умолчанию (1600×400).
- `assets/Logo/` — знак для тёмных и светлых фонов и значок приложения.
