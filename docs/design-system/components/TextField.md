Однострочное поле ввода: поиск, название сцены, адрес репозитория.

**Передаёшь:** `label`, `value` и `onChange` (или `defaultValue`), `placeholder`, `icon` (слева, например `search`), `type`, `clearable`, `hotkey` (подсказка клавиши в пустом поле), `hint`, `error`, `disabled`, `width`.

- Высота `target-min`, фон `surface-raised`, контур `border-strong` (контур поля обязан читаться, 3:1). Фокус: кольцо `focus-ring` вокруг всего поля.
- Подпись над полем `label` 13px, подсказка и ошибка под полем `caption`. Ошибка: контур и текст `danger`, текст говорит, как исправить («Enter a full https:// address»), без восклицательных знаков.
- Поиск: значок `search` слева, кнопка очистки появляется, когда есть текст. В списках поиск фильтрует сразу, без кнопки «Найти».
- Кнопка очистки 32px внутри поля: исключение из правила 40px, целью нажатия остаётся само поле.
- Плейсхолдер не заменяет подпись в формах; без подписи поле допустимо только для поиска.
