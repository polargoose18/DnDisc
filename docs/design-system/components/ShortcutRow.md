Строка таблицы горячих клавиш: действие, описание, клавиши, изменение.

**Передаёшь:** `action`, `description`, `keys` (список), `editable` или `onEdit`.

- Действие `body`, описание `caption`; клавиши в `dd-kbd` с рамкой справа, альтернативы через «or».
- Строки разделены линией `border`, без зебры. Группы (Playback, Intensity, SFX slots) с заголовками `caption` прописными над группой.
- Изменение: кнопка `edit` переводит клавишу в режим записи («Press keys…»); конфликт показывается ошибкой под строкой.
