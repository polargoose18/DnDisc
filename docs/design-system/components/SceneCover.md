Обложка сцены: изображение на всю область (cover, по центру) с необязательным затемнением. В каталоге есть 7 обложек по умолчанию в минималистичном стиле, пользователь может назначить свою.

**Передаёшь:** `cover` (ключ из набора), `src` (своё изображение, приоритетнее), `seed` (строка, например id сцены: из неё детерминированно выбирается обложка), `dim` (затемнение 0–100, процент цвета `bg` поверх), `fill` (занять всю область родителя, `position: absolute; inset: 0`), `height`, `width`, `radius` (число в px или строка), `className`, `style` (объект).

Размеры задаём свойствами `height`, `width`, `fill`, а не внешним стилем: у самой обложки нет собственной высоты.

| Ключ | Что |
|---|---|
| `peaks` | Горы и луна |
| `tower` | Башня на закате |
| `forest` | Хвойный лес |
| `sea` | Море, закат и парус |
| `gate` | Арка с огнём |
| `dunes` | Дюны |
| `village` | Ночная деревня |

- Приоритет: своя картинка пользователя, затем сохранённый ключ обложки, затем обложка по `seed`.
- Случайное назначение делается один раз при создании сцены и сохраняется (поле `cover` в таблице сцен), а не пересчитывается при отображении: сцена не должна менять картинку при перезапуске. Во Flutter `SceneCoverService.pickRandom()` возвращает ключ.
- Размеры: обложки 1600×400, фокус примерно по центру; показываются через `BoxFit.cover`, поэтому и в шапке 120px, и в миниатюре 40px, и в карточке каталога читаются. Ничего важного у краёв нет.
- Шапка сцены: `dim` 55, чтобы название `display` читалось в любой теме. Миниатюра в списке и карточка каталога: без затемнения.
- Стиль набора: плоские формы, 3–4 приглушённых цвета, один светлый источник (луна, солнце, огонь), без текста, градиентов и мелких деталей. Новые обложки рисуем так же; цвет обложки не участвует в палитре интерфейса.
- SVG-исходники: `assets/Covers/<ключ>.svg`.
