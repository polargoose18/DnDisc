Ползунок громкости или позиции. Дорожка 4px, область нажатия по высоте `target-min`.

**Передаёшь:** `value`, `min`, `max`, `onChange(number)`, `icon` или `label`, `showValue` (по умолчанию процент справа), `format` для своего вывода (время).

- Заполнение `primary`, остаток `surface-hover`. Бегунок 16px с кольцом цвета `surface`, чтобы он читался на заливке.
- Значение справа `caption`, `text-muted`, цифры табличные, ширина 36px: подписи не прыгают при движении.
- Канал определяет иконка (music, waves, volume) или короткая подпись. Цвет канала не меняй: акцент один.
- Стрелки меняют значение на 1, Shift+стрелки на 10; фокус показывает `focus-ring`.
