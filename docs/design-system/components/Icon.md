Значок из набора DnDisc: все 65 значков приложения (служебные, SFX, эмбиенты) нарисованы одним стилем. Material Symbols больше не нужны.

**Передаёшь:** `name`, `size` (по умолчанию 20). Цвет берётся из `currentColor`: `text-muted` в покое, `primary` у выбранного, играющего или включённого.

- Сетка 24×24, линия 1.75, скруглённые концы и углы, без заливок. Исключение: `play`, `pause`, `stop`, `bolt`, `more` залиты (линия 1.5 даёт им скруглённые углы), и точки внутри значков (ручка двери, дыхание шёпота).
- Размеры 16, 20 и 24. Служебные значки 20, значок звука в плитке SFX 24, кнопка слоя 22, навигация 20.
- Значок звука или слоя принадлежит ему и хранится в библиотеке под строковым ключом (`rain`, `door`). Пользователь выбирает его при добавлении; по умолчанию `bolt` для SFX и `waves` для эмбиента.
- Новый значок рисуем на той же сетке одним контуром 1.75, без деталей тоньше 1.5px на 24px, без градиентов, теней и цвета. Сначала ищем среди существующих.
- SVG-файлы: `assets/Icons/<ключ>.svg`, по одному на значок.
