Модальное окно: создание и редактирование сцены, импорт, подтверждение необратимого действия.

**Передаёшь:** `title`, `description`, `icon`, `tone` (`danger` для подтверждения удаления), `size` (`sm` 440, по умолчанию 560, `lg` 720), `actions` (список `{label, variant, icon, onClick}` или готовые кнопки), `footNote`, `onClose`, `inline` (без затемнения, для макетов), содержимое как `children`.

- Панель `surface`, рамка `border`, `radius-lg`, тень `shadow-overlay`, слой `z-dialog`. Затемнение: 72% цвета `bg`, без размытия.
- Шапка: заголовок `title-lg`, описание одной строкой, закрыть справа. Тело с отступом `space-5` и зазором `space-5` между полями. Подвал с границей сверху, действия справа: последнее главное.
- Главное действие одно: `primary` для сохранения, `danger` для удаления. «Cancel» всегда `ghost` слева от главного.
- Подтверждение удаления: размер `sm`, значок `trash` в плашке `danger-subtle`, текст называет, что будет удалено и что останется.
- Esc и клик по затемнению закрывают окно без сохранения; если форма изменена, сначала спрашиваем.
- Появление `duration-slow` с `easing-standard`: прозрачность и сдвиг на 8px снизу; без масштабирования.
