Выбор одного из нескольких вариантов. Главное применение: уровень интенсивности музыки сцены (Calm, Suspense, Battle, Boss).

**Передаёшь:** `options` (`id`, `label`, необязательные `color` и `key`), `value`, `onChange`, `label` для доступного имени группы.

- На экране ровно один переключатель интенсивности, в шапке сцены. В карточке Music его не дублируют.
- Выбранный сегмент: контур и тонированная заливка цвета интенсивности (`intensity-*`), текст `text`. Невыбранные без заливки, точка цвета остаётся.
- Цвет никогда не единственный признак: рядом название и цифра горячей клавиши 1–4.
- Сегмент высотой `target-min`; на узком экране сегменты сворачиваются в только цифры с точкой.
