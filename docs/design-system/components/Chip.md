Короткая метка: тег звука, выбранный фильтр по тегам.

**Передаёшь:** `label`, `icon`, `selected`, `onClick` (чип-переключатель, `aria-pressed`), `onRemove` (крестик).

- Статичный тег: высота 24px, `surface-hover`, текст `text-muted` 12px. Не больше трёх тегов в строке трека, остальные в карточке редактирования.
- Чип-переключатель: высота 32px, выбранный на `primary-subtle`. Используется для фильтра по тегам, где выбрать можно несколько.
- Для одного выбора из нескольких (тип: All, Music, Ambient, SFX) используется `SegmentedControl`, не ряд чипов.
- Цветных тегов нет: цвет у системы один, теги различаются текстом.
