Кнопка действия. Один вариант `primary` на экран, остальные действия `secondary` или `ghost`.

**Передаёшь:** `variant` (`primary`, `secondary`, `ghost`, `danger`, `transport`), `icon`, `iconOnly` вместе с `label` для доступного имени, `hotkey` для подсказки клавиши, `size="lg"` (48px).

- `primary` залит `primary`, текст `on-primary`. Не больше одной на видимую область: «Create scene», «Save».
- `secondary` на `surface-raised` с контуром `border`: обычные действия панели («Import», «Add»).
- `ghost` без фона, цвет `text-muted`; для действий внутри строк и иконок. Иконка-кнопка всегда имеет `label`.
- `danger` только контур и текст `danger`, без заливки. Всегда с подписью, иконка одна; на экране не больше одной такой кнопки.
- `transport` круг 48px, единственный вариант с `radius-full`: play/pause главного плеера, не больше одного на экран.
- Высота не ниже `target-min` (40px). Меньше не делать, даже в плотных списках: увеличивай область строки, а не уменьшай кнопку.
- Не ставь две иконки в одну кнопку и не добавляй свечение.
