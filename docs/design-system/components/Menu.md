Список действий над объектом: меню `more` у трека, слоя, сцены, карточки каталога.

**Передаёшь:** `items` (`{id, label, icon, hotkey, danger, disabled, checked}` или `{separator: true}`), `onSelect`, `label`.

- Панель `surface-raised`, рамка `border`, `radius-md`, тень `shadow-overlay`, слой `z-menu`. Пункт высотой `target-min`, значок `text-muted` 18px слева.
- Удаление последним, после разделителя, цветом `danger`; без подтверждения удаляется только то, что можно вернуть.
- Если у части пунктов есть значки, у остальных оставляется отступ, чтобы подписи стояли в одну колонку.
- Меню открывается по кнопке `more` и по правому клику на строке; закрывается выбором, Esc и кликом мимо.
