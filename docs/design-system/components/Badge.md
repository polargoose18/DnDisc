Короткая метка состояния: Playing, Paused, Imported, File missing.

**Передаёшь:** `tone` (`neutral`, `primary`, `success`, `danger`), `dot` для точки, текст в `children`.

- Всегда с текстом; точка только усиливает. Одно слово, регистр как в l10n.
- Один бейдж на элемент. Состояние «Активно» у сцены показывается строкой и иконкой, а не повторным бейджем.
- Тон `primary` обозначает текущее воспроизведение, `danger` ошибку или отсутствующий файл. Не используй бейдж как кнопку.
