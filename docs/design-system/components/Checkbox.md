Флажок для независимой настройки, которая применяется после сохранения или влияет на поведение (приглушать музыку, зацикливать слои).

**Передаёшь:** `label`, `description`, `checked` и `onChange` (или `defaultChecked`), `disabled`.

- Квадрат 20px, `radius-sm`, контур `border-strong`; включено: заливка `primary`, галочка `on-primary`. Вся строка кликабельна, высота не меньше `target-min`.
- Мгновенный переключатель (включить горячие клавиши, слой эмбиента) остаётся `Switch` или кнопкой слоя; `Checkbox` для списков опций в настройках и диалогах.
- Описание `caption` под подписью объясняет последствие, а не повторяет подпись.
