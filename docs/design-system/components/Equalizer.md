Минималистичный индикатор звука: несколько тонких вертикальных полос. Единственный анимированный элемент интерфейса, он показывает, что звук идёт прямо сейчас.

**Передаёшь:** `active` (играет), `bars` (число полос, по умолчанию 4), `height` (px, по умолчанию 16), `levels` (необязательный массив 0–1: реальные уровни звука), `className`.

- Где стоит: у включённого слоя эмбиента (после названия), у играющей плитки SFX (на месте клавиши), у активной сцены (вместо значка громкости), у статуса трека в нижнем микшере и широкой полосой (`dd-eq--wide`, 48 полос) в карточке Music.
- Играет: полосы цвета `primary` колышутся. Пауза или выключено: полосы статичные, цвет `text-muted`, высота низкая. Цвет сам по себе статус не передаёт: рядом всегда текст («Playing»), название или состояние плитки.
- Без `levels` движение имитируется: у полос разные периоды 0.9–1.6s, фаза сдвинута. С `levels` полосы следуют данным без анимации, плавность 80ms.
- Полоса 3px, зазор 2px, скругление 1px; радиус не из шкалы, потому что это не контрол. Свечения, градиента и отражения нет.
- `prefers-reduced-motion`: анимация отключается, полосы показывают статичный рельеф.
- Не больше одной широкой полосы на экран, малые полосы только у того, что играет.
- Во Flutter: `EqualizerBars` на `AnimationController`; если `AudioEngineService` отдаёт амплитуду, передаём её как `levels`, иначе имитация; при `MediaQuery.disableAnimations` рисуем статично.
