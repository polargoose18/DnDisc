Квадратная плитка одноразового звука со значком, привязанным к конкретному звуку. Сетка плиток заполняет ширину правой колонки.

**Передаёшь:** `label`, `icon` (значок звука), `hotkey` (клавиша 1–9), `playing`, `progress` (0–100), `onClick`; `empty` для пустого слота добавления.

- Плитка строго квадратная (`aspect-ratio: 1`), минимальная сторона `sfx-tile-min` (96px). Значок 24px слева сверху, подпись до двух строк внизу, клавиша справа сверху. Если плиток больше, чем помещается по высоте, сетка прокручивается внутри панели.
- Значок принадлежит звуку и хранится вместе с ним в библиотеке: пользователь выбирает его при добавлении звука. Значки из набора `Icon` (16 для SFX); без выбранного стоит `bolt`.
- Играет: фон `primary-subtle`, контур `primary`, полоска прогресса 3px внизу; на месте клавиши появляется `Equalizer` (3 полосы), клавиша вернётся после остановки. Нажатие запускает звук сразу, без подтверждения.
- Пустой слот: пунктир `border-strong`, иконка `plus`. Он последний в сетке.
- Цвета категорий не вводим: значок `text-muted`, у играющей плитки `primary`.
