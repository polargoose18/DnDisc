# Аудит текущего интерфейса

Основа: скриншот GM Dashboard и код `lib/ui` и `lib/domain/models/custom_theme_model.dart`. Для каждого наблюдения указано решение дизайн-системы.

| Что сейчас | Решение |
| --- | --- |
| Переключатель интенсивности есть дважды: в шапке сцены (`scene_backdrop_header.dart`) и в карточке Music (`music_player_panel.dart`). | Один переключатель в шапке сцены. Из карточки Music убрать. |
| Громкость разбросана: слайдер в Music, SFX Volume в SFX, громкость слоя в строке, общая сверху и ещё внизу. | Один нижний микшер: Music, Ambient, SFX, Master. Громкость слоя остаётся в строке слоя. |
| На экране одновременно янтарный, бирюзовый, фиолетовый, красный, оранжевый и серо-синий. Нет главного. | Один акцент `primary`; цвета интенсивности вынесены в отдельную смысловую палитру и используются только в переключателе. |
| 36 мест с шрифтом 9–11px, в том числе «Volume: 80%». | Минимум 12px (`caption`), у всего, что читают во время игры, 14px и выше. |
| В `ThemeData` и виджетах 49 вхождений `Colors.white` как цвета текста на акценте. Белый на `#D4A373` даёт 2.3:1, на изумрудном `#34D399` 1.9:1. | Токен `on-primary` в каждой теме, контраст не ниже 4.5:1. |
| Серифный шрифт задан через `fontFamilyFallback: [Georgia, …]` в 10 местах. | Один гротеск IBM Plex Sans в `TextTheme`, без точечных переопределений. |
| В коде встречаются радиусы 4, 6, 8, 10, 12, 13, 14, 16, 20. | Три радиуса: 4, 8, 12 и `radius-full` для трёх элементов. |
| Строка слоя Ambient: переключатель, mute, pin, закрыть, ползунок: пять контролов, два из них дублируют друг друга. | Переключатель (он же mute), ползунок и меню `more` с закреплением и удалением. |
| Бейдж ACTIVE и кнопка ACTIVE на одной карточке сцены; «Paused» и «Now playing» почти не различаются. | Активная сцена: подсветка строки и иконка. Состояние плеера: один бейдж в заголовке Music. |
| Hero-баннер сцены занимает до трети высоты и повторяется на каждой вкладке компактного режима. | Компактная шапка `scene-header-height` (120px) с названием сцены и переключателем интенсивности; на компактном экране один раз над вкладками. |
| Правая колонка заканчивается на середине экрана, SFX-сетка не растёт. | Сетка SFX заполняет высоту колонки, пустой слот `plus` в конце. |
| Свечение и разные тени у карточек. | Только границы; тень `shadow-overlay` у плавающих слоёв. |
| Panic Stop в заголовке SFX как мелкая красная кнопка. | Кнопка и клавиша Esc удалены из приложения; отдельной замены в дизайне нет. |
| В `_buildDesktop3ColumnLayout` условие `isWideWorkstation` (ширина ≥ 950) всегда истинно: сюда попадают только окна от 1000px. | Брейкпоинты в разделе «Раскладка»; вторая ветка нужна, когда рабочая область, а не окно, уже порога. |
