# Раскладка

## GM Dashboard, окно от 1000px

Каркас: свёрнутая навигация слева, панель сцен, рабочая область, нижний микшер. Верхняя панель над рабочей областью.

```
+------+----------+----------------------------------------------+
| rail | scenes   | topbar: сцена                                 |
| 64   | 280      +----------------------------------------------+
|      | search   | scene header 120: название + интенсивность    |
|      | scene    +----------------------+-----------------------+
|      | scene    | Music                | SFX                   |
|      | scene    | Ambient layers       | (сетка на всю высоту) |
+------+----------+----------------------+-----------------------+
| mixer 72: трек · transport · Music · Ambient · SFX | Master    |
+---------------------------------------------------------------+
```

- Размеры из токенов `size`: `rail-width`, `scenes-width`, `topbar-height`, `scene-header-height`, `mixer-height`. Зазоры между панелями `space-4`.
- Рабочая область делится на две колонки 1.2 : 1. Слева Music и Ambient layers, справа SFX; сетка SFX заполняет ширину колонки плитками от `sfx-tile-min`, высота растёт вместе с окном.
- Шапка сцены: название `display` слева, переключатель интенсивности справа; фоновая картинка сцены затемнена и занимает только шапку.
- Верхняя панель: название экрана или сцены слева, справа поиск (в списках).

## Окно 700–999px

- Рейл остаётся свёрнутым, панель сцен прячется в выезжающую панель по кнопке в верхней панели.
- Колонки Music/Ambient и SFX становятся одной колонкой, порядок: интенсивность, Music, SFX, Ambient. Микшер показывает Master, остальные каналы в поповере.

## Окно до 700px (компактный режим)

- Нижний микшер остаётся, вместо рейла нижние вкладки: Scenes, Music, Ambient, SFX. Шапка сцены с интенсивностью один раз над вкладками, не повторяется в каждой.

## Экраны Library, Catalog, Settings

Общий каркас: рейл слева, верхняя панель 56px с заголовком экрана `title-lg` и действиями справа, контент на `bg`, нижний микшер на всех экранах (музыка не прерывается при переходе).

- **Media Library.** Под верхней панелью строка инструментов: `TextField` поиска на всю ширину, справа `SegmentedControl` типа (All, Music, Ambient, SFX) с количеством. Действия экрана в верхней панели: «Export set» (`secondary`), «Import» (`primary`). Список треков в панели `surface` строками `TrackRow`; пути к файлам только в подсказке. Перетаскивание файлов на список подсвечивает его как `Dropzone`; пустая медиатека показывает `EmptyState` с зоной импорта. Прогресс импорта в `Toast` внизу справа.
- **Catalog.** Строка инструментов: поиск и `SegmentedControl` (All, Scenes, Media, Bundles). Действия в верхней панели: обновить (иконка), «Sources» с количеством (`secondary`), «Add source» (`primary`). Сетка `CatalogCard` `repeat(auto-fill, minmax(240px, 1fr))`. Недоступный источник: `EmptyState` с «Retry», не красная плашка.
- **Settings.** Одна колонка не шире 880px по центру, разделы-панели: Appearance (`ThemeCard` в сетке по 5, последняя «Create theme»), Audio (устройство `Select`, кроссфейд `Slider`, опции `Checkbox`), Shortcuts (`Switch` в заголовке панели, группы `ShortcutRow`), About (`Logo` с подписью, версия, ссылки). Заголовок раздела `title`, без крупных круглых значков.
- **Диалоги.** Создание и редактирование сцены `Dialog` `lg`: название, обложка (7 обложек + своя картинка), интенсивность по умолчанию, музыка, слои и SFX списками `TrackRow` с флажками. Импорт `Dialog` с `Dropzone` и списком файлов. Удаление `Dialog` `sm` с `danger`.

## Горячие клавиши на экране

- 1–4 интенсивность (Calm, Suspense, Battle, Boss), 1–9 плитки SFX при фокусе на сетке, пробел play/pause. Клавиши показывает `dd-kbd` рядом с элементом; на плитках SFX номер совпадает с позицией.

## Другие платформы (M7, M8)

- Токены остаются, меняется только `size` и масштаб шрифта: телефон и планшет `target-min` 48px, шрифт ×1; ТВ `target-min` 64px, шрифт ×1.25, фокус кольцом `focus-ring` 3px, управление стрелками пульта.
- Веб-пульт на телефоне: четыре вкладки как в компактном режиме, SFX в сетке 2 колонки.
- ТВ-режим: шапка сцены на весь экран, рядом три индикатора слоёв; интерактивных элементов нет, пока GM-пульт не подключён.
