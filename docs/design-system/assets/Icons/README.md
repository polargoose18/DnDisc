65 значков DnDisc по одному файлу, сетка 24×24, линия 1.75, скруглённые концы. Список, группы и правила в карточке `Icon`.

- Чернила файлов `#b8a999` (`text-muted` Deep Dark) только для просмотра. В приложении цвет задаёт тема: во Flutter `ColorFilter.mode(color, BlendMode.srcIn)`, в вебе компонент `Icon` рисует `currentColor`.
- Залиты только `play`, `pause`, `stop`, `bolt`, `more`.
- Имя файла = ключ значка; ключ значка звука или слоя хранится в БД в поле `icon`.
