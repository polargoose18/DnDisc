Семь обложек сцен по умолчанию, 1600×400, плоские формы и один источник света. Правила и выбор обложки в карточке `SceneCover`.

- Ключ файла (`peaks`, `tower`, `forest`, `sea`, `gate`, `dunes`, `village`) хранится в колонке `cover` таблицы сцен.
- Показываются через `BoxFit.cover` (по центру); у краёв нет ничего важного, поэтому обрезка до шапки 120px, миниатюры 40px и карточки каталога безопасна.
- Цвета обложек не участвуют в палитре интерфейса и не меняются с темой. В шапке сцены поверх кладётся затемнение 55% цвета `bg`.
