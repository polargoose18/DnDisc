Логотип DnDisc: буква D из половины пластинки, канавка и акцентный шпиндель. Правила в карточке `Logo`.

- `logo-mark.svg` — знак для тёмных тем: контур `#f3ece2` (`text` Deep Dark), шпиндель `#d4a373` (`primary`).
- `logo-mark-light.svg` — знак для светлых фонов: контур `#1a1612`, шпиндель `#b9793a`.
- `app-icon.svg` — значок приложения: знак на `#14110f`, скруглённый квадрат 22%. Из него собираются `.ico`, `.icns` и иконки Linux.
- В интерфейсе знак рисует компонент `Logo` цветами текущей темы; файлы нужны для иконок платформ, README репозитория и экрана «О программе».
