# DnDisc — TTRPG Audio Master

**DnDisc** — это современный кроссплатформенный аудио-плеер, микшер атмосферных звуков и саундборд, созданный специально для Мастеров Подземелий (Game Masters / Dungeon Masters) в настольных ролевых играх (D&D, Pathfinder, Warhammer Fantasy, Call of Cthulhu и др.).

Приложение помогает мгновенно создавать нужную атмосферу за столом: от уютной шумящей таверны до эпического сражения с драконом или мрачных подземных катакомб.

---

## 🚀 Ключевые возможности

### 🎧 Трехслойный аудио-движок
* **Музыкальная шина (`Music`)**: Воспроизведение фоновых композиций с поддержкой плавного затухания (Crossfade) при смене трека.
* **Шина звуков окружения (`Ambient`)**: Независимый микшер слоёв амбиента (дождь, ветер, шум трактира, треск костра) с индивидуальной регулировкой громкости.
* **Шина звуковых эффектов (`SFX`)**: Мгновенный запуск разовых эффектов (рык монстра, удар меча, взрыв, звон монет) через интерактивную сетку саундборда.

### 🎭 Сцены, Медиа-наборы & Паки (Изолированный экспорт/импорт)
* **Смены атмосферы в 1 клик**: Сохраняйте комбинации музыки, громкостей амбиентов и горячих кнопок SFX в Сцены.
* **Экспорт отдельных сцен (`.scene.zip`)**: Экспортируйте конкретную сцену со всеми её медиафайлами.
* **Экспорт Наборов Медиа (`.media.zip`)**: Подборки треков/звуков для добавления напрямую в общую библиотеку.
* **Экспорт Паков сцен (`.pack.zip`)**: Комплексные наборы приключений, объединяющие сразу несколько сцен.
* **Автоматическая дедубликация**: Импортируйте контент без повторного копирования одинаковых аудиофайлов.

### 🌐 Каталог репозиториев (Jellyfin Style Catalog)
* **Разделы Каталога**: Фильтрация контента по чипам **`[Все]`**, **`[🎭 Сцены]`**, **`[🎵 Медиа]`**, **`[📦 Паки]`**.
* **Предварительный просмотр метаданных (`repository.json v2`)**: Просматривайте обложки, описания, авторов и полный состав треков **до скачивания**.
* **Авто-трансформация GitHub URL**: Поддержка добавления прямых ссылок на репозитории GitHub (например, `https://github.com/username/my-dnd-scenes`).
* **Автоматический скрипт-генератор**: Готовый инструмент [`tools/generate_repository_manifest.py`](tools/generate_repository_manifest.py), который собирает `repository.json` за 1 секунду без ручного написания JSON.

## 🎛 Продвинутые аудио-функции

* **Auto-Ducking**: Автоматическое приглушение фоновой музыки при воспроизведении звуковых эффектов (SFX) или речи.
* **Fading & Crossfade**: Плавная смена музыкальных треков и плавный запуск/остановка амбиент-слоёв.
* **Panic Stop**: Мгновенная остановка всех звуковых эффектов или всей аудиосистемы одной кнопкой.
* **Горячие клавиши**: Настраиваемые клавиатурные сокращения для быстрого управления треками и функциями.
* **Кастомные темы оформления**: Редактор цветовых тем интерфейса.
* **Локализация**: Полная поддержка русского и английского языков (i10n).

## 🛠 Технологический стек

* **Фреймворк:** Flutter Desktop (Windows / Linux)
* **Стейт-менеджмент:** `provider` (ChangeNotifier)
* **Аудио-движок:** `audioplayers` и `flutter_soloud`
* **База данных:** SQLite (`sqflite` / `sqflite_common_ffi`, версия БД v4)
* **Работа с архивами:** `archive` (`.scene.zip`, `.media.zip`, `.pack.zip`)
* **Инструментарий:** Python 3 скрипт сборки манифестов
